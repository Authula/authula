# OpenID Connect (OIDC Specifications)

Unlike OAuth 2.0 (which is managed by the IETF), OpenID Connect specifications are hosted and maintained directly by the **OpenID Foundation (OIDF)**. The core specifications include:

* **OpenID Connect Core 1.0** – Defines the foundational identity layer, ID Tokens, UserInfo endpoint, and authentication flows.
* **OpenID Connect Discovery 1.0** – Defines the `/.well-known/openid-configuration` discovery mechanism.
* **OpenID Connect Dynamic Client Registration 1.0**
* **OpenID Connect Session Management 1.0** – Manages browser sessions and login status tracking.
* **OpenID Connect Front-Channel Logout 1.0 & Back-Channel Logout 1.0** – Standardizes cross-application logout semantics.
* **OpenID Connect RP-Initiated Logout 1.0** – Standardizes how a relying party tells the provider to log the user out.

---

### Where to fetch them for your codebase:

* For all **IETF RFCs**, you can pull the raw text or markdown format directly from the [RFC Editor](https://www.rfc-editor.org/) (e.g., `https://www.rfc-editor.org/rfc/rfc7009.txt`) or index maps via [oauth.net/specs](https://oauth.net/specs/).
* For **OpenID Connect specs**, the canonical markdown and PDF documents are hosted on the [OpenID Foundation Specifications Site](https://openid.net/developers/specs/).
